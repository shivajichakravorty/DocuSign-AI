# 🛡️ DocuShield AI (Ongoing)

An intelligent document signing and legal risk audit platform.

---

## 🚀 Tech Stack

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend**: Node.js, Fastify
- **Database**: PostgreSQL
- **AI Service**: Python / Django *(in development)*

---

## ⚡ Current Status

- [x] End-to-end authentication (Register, Login, JWT session persistence)
- [x] Protected client routes and custom authentication hooks
- [x] Modern dark-mode dashboard and authentication views
- [x] PDF document upload, streaming & local disk storage handling
- [x] Relational database schema for envelopes, signers & signature tabs
- [ ] Interactive PDF viewer & tab placement canvas
- [ ] Multi-party signature workflow & guest signing links
- [ ] AI contract analysis & clause risk detection
